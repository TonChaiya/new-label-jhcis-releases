## สิ่งที่เปลี่ยนในเวอร์ชัน 2026.09.21.1

- บันทึกวิธีใช้แล้วพิมพ์ซ้ำเฉพาะฉลากยาที่แก้ไข โดยรองรับหลายรายการในคิวเดียว
- แก้เฉพาะ `visitdrug.dose` ของ Visit และรหัสยาที่เลือก ไม่เปลี่ยนจำนวน หน่วย ข้อมูลยา หรือสถานะ Visit
- งานพิมพ์ฉลากเดี่ยว/ฉลากแก้ไขไม่เปลี่ยน `visit.flagservice` เป็น `03`; คิว Auto ทั้ง Visit ยังคงทำงานเดิม
- ป้องกันการเขียนทับคิวที่กำลังพิมพ์ และเพิ่ม schema แบบย้อนหลังใน `autoprintdb` โดยรักษาคิวกับค่าตั้งเดิม
- รวมระบบจากรุ่นก่อนทั้งหมด ได้แก่ หน้าเว็บ/LAN client ลูกประคบแบบไม่รีเฟรช หน้าแก้วิธีใช้ Tray และ Updater
- Update ZIP เป็นชุดระบบเต็ม รองรับการข้ามหลายเวอร์ชัน และไม่เขียนทับ config, settings, log, output หรือฐานข้อมูลเดิม

อ่านรายละเอียดทุกรุ่นได้ที่ [CHANGELOG.md](CHANGELOG.md) และขั้นตอนใช้งานที่ [UPDATE_GUIDE.md](UPDATE_GUIDE.md)

คู่มือไฟล์ Setup/Update ของรุ่นนี้: [RELEASE_2026.09.21.1_TH.md](RELEASE_2026.09.21.1_TH.md)

## การรักษาข้อมูลเดิม

แพ็กเกจ Release ไม่มีรหัสผ่าน ข้อมูลผู้ป่วย Log หรือ Output จากเครื่องใช้งาน ระบบอัปเดตไม่เขียนทับไฟล์ตั้งค่าเฉพาะเครื่อง เช่น `config.php`, `autoprint_config.php` และ `settings.json`

การปรับ schema ทำผ่าน `Autoprint/setup_db.php` ในฐาน `autoprintdb` โดยไม่ลบข้อมูลเดิม และระบบจัดการคิวอัปเดตไม่แก้ฐาน `jhcisdb`
