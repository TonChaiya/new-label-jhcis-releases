## สิ่งที่เปลี่ยนในเวอร์ชัน 2026.08.11.9.5

- เพิ่มการตรวจซ้ำตามเวลาสำหรับ Visit ที่ฉลาก Auto Print พิมพ์สำเร็จแล้วเท่านั้น
- เก็บสถานะการซิงก์และข้อผิดพลาดไว้ใน `autoprintdb` เพื่อไม่ให้คิวที่พิมพ์แล้วสูญหายก่อนตรวจซ้ำ
- ตั้งเวลาได้หลายช่วงจากหน้าเคลียร์ข้อมูล พร้อมรหัสยืนยัน
- ป้องกันการสร้างคิว `waiting` ซ้ำจาก Visit ที่รับบริการเสร็จสิ้น (`03`) แล้ว
- คงปุ่มเคลียร์คิว JHCIS แบบแมนนวลสำหรับเปลี่ยน Z1/Y1 ทั้งหมดเป็น 03 ไว้เหมือนเดิม

## การรักษาข้อมูลเดิม

แพ็กเกจ Release ไม่มีรหัสผ่าน ข้อมูลผู้ป่วย Log หรือ Output จากเครื่องใช้งาน ระบบอัปเดตไม่เขียนทับไฟล์ตั้งค่าเฉพาะเครื่อง เช่น `config.php`, `autoprint_config.php` และ `settings.json`

การปรับ schema ทำผ่าน `Autoprint/setup_db.php` ในฐาน `autoprintdb` โดยไม่ลบข้อมูลเดิม และระบบจัดการคิวอัปเดตไม่แก้ฐาน `jhcisdb`
